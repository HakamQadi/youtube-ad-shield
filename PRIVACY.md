# Privacy

YouTube Ad Shield does not collect, transmit, sell, or share user data.

The extension:

- does not use analytics;
- does not make external network requests;
- does not send browsing activity to any server;
- stores only its local enabled/disabled state and handled-ad counter through Chrome storage;
- runs only on `youtube.com` and `m.youtube.com` pages declared in the manifest.

All ad handling happens locally in the browser.
