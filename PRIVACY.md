# Privacy Policy — Ad Shield for YouTube™

Ad Shield for YouTube™ is designed to operate locally in the user's browser.

## Data handled by the extension

The extension processes limited website content on YouTube pages in order to detect advertising states and identify available Skip Ad controls.

This processing happens locally on the user's device.

The extension does not transmit YouTube page content, browsing information, or other user data to the developer or to external servers.

## Local storage

The extension uses Chrome's storage API to save:

- Whether protection is enabled or disabled
- The local Ads Handled counter

This information remains on the user's device and is used only to provide the extension's functionality.

## Data sharing

Ad Shield for YouTube™ does not:

- Sell user data
- Share user data with third parties
- Use user data for advertising
- Use analytics or tracking services
- Transmit browsing activity to external servers
- Collect personally identifiable information
- Collect financial, health, authentication, location, or communication data

## Website access

The extension operates only on:

- https://www.youtube.com/*
- https://m.youtube.com/*

Access to these pages is required solely to provide automatic YouTube ad-handling functionality.

## Remote code

The extension does not download or execute remote JavaScript or WebAssembly code. All executable extension code is included in the extension package.

## External links

The extension popup contains a user-initiated link to the developer's portfolio. No extension data is sent to the portfolio website by the extension.

## Limited Use

Any information processed by the extension is used only to provide the extension's disclosed single purpose.

Ad Shield for YouTube™ complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
